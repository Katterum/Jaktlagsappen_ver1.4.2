# Jaktlaget 1.4.2

## Ändringar
- Mer-sidan innehåller nu endast valknappar.
- Varje funktion öppnas på en ren separat sida med tillbaka-knapp.
- Genomförda jakter har flikarna Registrera och Historik.
- Viltobservationer har flikarna Registrera och Historik.
- Jakter och observationer kan ändras eller raderas i efterhand.
- Redigering omfattar datum, typ/art, deltagare/observatör, gäster, plats, antal, riktning och kommentar.
- Skapad och senast ändrad visas i historiken.
- Befintlig lokal data migreras från 1.4.1 och äldre versioner.
